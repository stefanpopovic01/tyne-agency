# Tyne Agency — Website

Modern performance marketing website built with React + Vite.

---

## Pages

| Route | Description |
|-------|-------------|
| `/` | Home — all main sections |
| `/kontakt` | Contact page with form |
| `/zakazi-call` | Book a call with date & time picker |

## Sections (Home)

- **Hero** — main headline, stats, animated dashboard card
- **O nama** — about section with pillar cards
- **Usluge** — interactive tabbed services (Google, Meta, TikTok, LinkedIn Ads)
- **Paketi** — pricing cards (Single Platform / Full Funnel)
- **Zašto mi + Kako radimo** — value props and 3-step process
- **FAQ** — accordion with 8 questions
- **CTA** — client logo ticker + book call section

---

## Tech Stack

- **React 18** + **Vite**
- **React Router v6** — client-side routing
- **CSS Modules** — scoped per component (no Tailwind, no UI library)
- No backend — contact form ready for [Formspree](https://formspree.io)


## Getting Started

```bash
npm install
npm run dev
```
